## 🚀 Main Project

### 🤖 Jarvis Assistant (Python)

A command-line based personal assistant built using Python, capable of handling multiple utility tasks.

#### Key Features:

* Open websites (YouTube, Google, GitHub, etc.)
* Perform calculations with error handling
* Save and read notes using file handling
* Display current time (12-hour format)
* Search queries directly in browser

#### What Makes It Important:

* Uses function-based modular structure
* Implements dictionary-based command handling
* Handles invalid inputs using exception handling
* Built with focus on real debugging and improvement

👉 This is my most complete and structured Python project.
