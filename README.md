### 2. Snake Water Gun Game
A two-player console game based on the classic Snake–Water–Gun rules.

Features:
- Takes input from both players
- Decides winner using game rules
- Keeps track of both players' scores
- Exit option using -1

Concepts used:
- while loop
- if / elif / else
- lists
- variables
- user input

Run:
python snake_water_gun.py
